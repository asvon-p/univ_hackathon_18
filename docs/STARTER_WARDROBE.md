# 신규 가입 예시 옷장

회원가입 시 아우터·상의·하의 각 3벌, 총 9벌을 생성합니다. 직접 옷을 올리거나
신체 정보·전신 사진을 등록하지 않아도 바로 코디 추천을 받을 수 있습니다.
착샷 생성에는 기존과 같이 전신 사진이 필요합니다.

## 사용자 경험

- 가입 안내 → 선택 프로필의 **예시 옷장으로 바로 시작하기** → 옷장 → **이 옷으로 코디 추천받기**.
- 카드와 상세 화면에서 예시임을 표시합니다. 일반 옷처럼 수정·삭제·상태 변경할 수 있습니다.
- 본인 옷도 계속 등록할 수 있습니다. 추천은 사용 가능한 예시 옷과 본인 옷 전체를 사용합니다.
- 새 계정에만 한 번 생성합니다. 기존 계정에 추가하지 않으며, 로그인·서버 재시작·삭제 후 다시 생성하지 않습니다.

## 저장 및 운영

- `backend/assets/starter_wardrobe/`에 생성된 가상 의류 원본 JPEG 9장, WebP 썸네일 9장,
  속성·체크섬 목록을 포함합니다. 앞이 열린 아우터를 사용하며 사용자 사진은 사용하지 않습니다.
- 가입 시 GPT·Vision을 호출하지 않습니다. 준비된 색상·스타일·보온도 등을 복사하므로 바로 추천에 쓸 수 있습니다.
- 사용자마다 별도 의류 UUID 및 `user_id/garment_id/` 이미지 경로를 생성합니다. 소유자 인증과
  사용자별 추천·파일 접근 제한은 기존 경로를 사용합니다.
- 사용자·프로필·9벌의 행은 한 트랜잭션으로 저장합니다. 실패 시 롤백 후 계정 파일 정리 작업을
  등록하며 파일 삭제 실패는 기존 정리 작업자로 재시도합니다. 커밋 응답만 유실된 경우 살아 있는 계정 파일을 보존합니다.
- DB가 계속 중단돼 정리 작업조차 기록하지 못하면 오류 로그가 남습니다. 이 경우 접근할 수 없는
  파일이 남을 수 있으므로 복구 후 운영 점검이 필요합니다.
- 마이그레이션 `0024`는 `garments.is_example`만 추가합니다. 기존 행은 모두 `false`이며
  사용자 업로드도 기본 `false`입니다. 응답의 `is_example`은 읽기 전용입니다.
- `STARTER_WARDROBE_ENABLED`는 기본 `true`입니다. 기존 테스트는 명시적으로 끄고,
  전용 API·HTTP E2E 테스트에서 켜서 검증합니다. 배포 시 이미지 디렉터리 전체를 포함하세요.

## 검증

- 신규 가입 3×3벌, 원본·썸네일 조회, 실제 local 추천, 중복 가입·로그인 시 중복 생성 방지.
- 예시 수정·삭제·본인 옷 추가, 타 사용자 조회·수정·삭제·이미지 차단, 탈퇴 시 본인 파일만 정리.
- 파일 저장 실패, DB 커밋 실패, 정리 실패 재시도, 커밋 응답 유실 시 데이터 보존.
- 실제 PostgreSQL의 임시 스키마에서 API·마이그레이션·로컬/멘토 HTTP 화면 흐름을 검증합니다.
- `.env`를 읽지 않습니다. 테스트에는 `FITJANG_SKIP_DOTENV=1`과 명시적인 테스트 DB를 사용합니다.

## 적용 중 확인한 Windows 의존성 상태 (2026-11-14)

- Windows 응용 프로그램 제어 정책이 기존 psycopg 네이티브 DLL을 차단했습니다.
  정책을 해제하지 않고 `pg8000` 순수 Python 드라이버로 같은 DB·스키마에 연결하도록 복구했습니다.
  연결 옵션을 무시하지 않으며, 지원하지 않는 옵션이 있으면 전환하지 않고 오류를 반환합니다.
- `rembg → pymatting → numba` 경로의 `_helperlib` DLL도 차단된 상태입니다. 이미지 모델의
  ImportError가 회원가입·옷장·추천 서버 전체를 중단시키지 않도록 격리했습니다.
  이후 동일 U²-Net 가중치를 ONNX Runtime으로 직접 실행하도록 바꿔 신규 사진 자동 분석·누끼를 복구했습니다.
  차단된 DLL은 실행하지 않으며 Windows 정책도 유지합니다. 로컬·멘토 `/health`는 모두
  `status=ok`, `vision_error=null`입니다. 실행 중인 GPU 착샷 서버는 재시작하지 않았습니다.
  실제 PostgreSQL 및 화면 검증 결과는 [복구 기록](VISION_RECOVERY.md)을 참고하세요.
