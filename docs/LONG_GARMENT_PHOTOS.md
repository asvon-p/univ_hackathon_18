# 긴 옷 등록 — 2026-11-13

옷 등록의 사진 형태에 `일반 옷 — 정사각형 1:1`과 `롱패딩·긴 코트 등 — 세로 2:3`을 제공합니다.
기본은 1:1이며, 긴 옷은 사진 선택 전 또는 자르기 도중 2:3으로 전환합니다.

- 일반 옷: 1080×1080 JPEG, 기존 정사각형 자르기 유지.
- 긴 옷: 1080×1620 JPEG. 원본 전체를 틀 안에 맞추고 네 변에 최소 3% 여백을 둡니다. 더 긴 사진도 흰 여백을 허용하여 목·소매·밑단이 잘리지 않게 시작합니다. 사용자가 확대하면 일부 영역이 잘릴 수 있으므로 미리보기에서 확인합니다.
- 웹 카메라: 선택한 비율로 카메라를 요청합니다. 긴 옷 모드는 실제 카메라 프레임 전체를 자르기 화면으로 전달합니다. 기기가 요청 비율을 지원하지 않아도 전체 프레임을 보존합니다.
- 기본 카메라: 운영체제 카메라 앱의 촬영 비율을 웹이 강제할 수 없습니다. 촬영 후 선택한 1:1 또는 2:3 틀에서 조절합니다.
- 전신 사진: 기존 2:3 및 머리·발끝 여백 정책을 유지합니다.
- 의류의 종류·세부 종류는 기존 분석/확인 단계에서 결정합니다. 사진 비율을 선택한다고 자동으로 아우터나 패딩으로 확정하지 않습니다.

`POST /garments/new`는 `photo_mode=square|long`을 받아 실제 정규화된 사진 비율을 검사합니다.
모드 생략 시 기존 요청대로 정사각형을 사용합니다. 잘못된 비율은 저장 전에 거절하며 선택한 모드를 유지해 안내합니다.
백엔드는 기존 비정사각 이미지 지원을 그대로 사용하므로 DB 마이그레이션이나 기존 데이터 변환은 없습니다.

## 검증

- 실제 PostgreSQL 임시 스키마와 HTTP 서버를 사용한 긴 옷/기존 옷/전신 사진 E2E 및 공개 경계 회귀: 최종 결과 기준 55개 통과. 신규 테스트의 초기 응답 형식 가정 오류 2개는 실제 배열 응답에 맞춰 수정하고 재실행했습니다.
- 세로 사진의 위·아래 색상 표식 보존, 실제 저장 크기, 잘못된 모드·비율 거절, 타 사용자 이미지 404, 기존 정사각 업로드를 검증했습니다.
- 실제 브라우저에서 생성된 코트 사진과 450×1350 테스트 이미지를 사용해 모드 전환·전체 사진 보존·1080×1620 결과 생성·등록을 확인했습니다. 멘토 HTTPS에서도 신규 선택지와 공유된 등록 결과를 확인했습니다.
- 이번 작업에서 휴대폰 실기기 촬영을 다시 수행하지는 않았습니다. 개인 사진은 사용하지 않았습니다.
- 임시 검증 계정과 서버 파일은 정리했습니다. 기존 계정 6개·의류/속성 각 39개·추천 68개·코디 88개 및 기존 파일 112개의 행/메타데이터 대조에서 변경이 없었습니다.
- 로컬·멘토 서버 재시작 완료, GPU/자동 실행기 ready. `.env` 직접·간접 접근은 금지하고 실행기·검증의 audit hook을 유지했습니다.
