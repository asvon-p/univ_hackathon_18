# 실사 스타일 시연 옷장

2026-11-08, 사용자 요청으로 공개 `mentor-demo@example.com`과 로컬 `local-test@example.com`의
기존 의류를 교체했습니다. 내장 image_gen으로 생성한 원본 PNG 9장을 두 계정에 각각 등록했습니다.
여기서 오브젝트는 사진과 속성이 연결된 옷장 의류 레코드이며 별도 3D 모델 파일은 아닙니다.

| 종류 | 의류 3종 |
| --- | --- |
| 상의 | 아이보리 케이블 니트, 화이트 옥스퍼드 셔츠, 네이비 풀오버 후디 |
| 하의 | 미디엄 블루 스트레이트 데님, 차콜 스트레이트 슬랙스, 베이지 코튼 치노 팬츠 |
| 아우터 | 올리브 봄버 재킷, 베이지 싱글 트렌치코트, 인디고 데님 트러커 재킷 |

모두 `available` 상태이며 카테고리·세부 종류·색상·스타일·보온도를 입력했습니다.
차콜은 공통 데이터 계약에 맞춰 `gray`로 저장하고 이름에 차콜을 표시합니다.
이미지는 흰 배경의 정면 상품 사진 구도로 원단 질감과 입체감이 드러나도록 생성했습니다.

## 저장 위치

- 원본 이미지·속성·생성 프롬프트: `.demo/wardrobe-v2/catalog.json`과 같은 폴더의 PNG 9장.
- 계정별 새 의류 ID·API 레코드·검증 결과: `.demo/wardrobe-v2/{mentor,local}/replacement.json`.
- 원본 9장·카탈로그·두 계정의 새 의류 데이터 묶음: `.demo/wardrobe-v2/wardrobe-assets.zip`.
  이전 이미지·백업·인증정보는 이 ZIP에 포함하지 않습니다.
- 교체 전 DB 기록·의류 이미지: 각 계정 폴더의 `before.json`, `old-images/`.
- 교체 직후 DB 상태: 각 계정 폴더의 `after.json`.
- 새 의류로 받은 추천: 각 계정 폴더의 `recommendation.json`.
- 위 시연 데이터와 백업은 `.demo/` 아래에 있으며 Git에서 제외됩니다.

## 교체와 보존

새 9벌을 업로드하고 속성·이미지 조회를 모두 확인한 후 기존 의류를 삭제 API로 제거했습니다.
멘토 계정의 기존 9벌, 로컬 테스트 계정의 기존 3벌과 해당 저장소 이미지가 제거됐습니다.
기존 계정·비밀번호·프로필·전신 사진 및 다른 사용자 데이터는 변경하지 않았습니다.

기존 삭제 정책에 따라 삭제된 옷을 포함한 코디 이력은 함께 제거됩니다.
교체 직전 멘토 코디 69건·로컬 코디 18건은 `before.json`에 백업했습니다.
추천 요청 기록은 유지되며 피드백 4건도 보존하고 삭제된 코디 참조만 NULL로 변경됩니다.
백업은 참고·복구용 파일이며 화면에서 자동 복원되는 휴지통은 아닙니다.

멘토 `seed.json`도 새 ID로 갱신했으므로 정상 재시작 시 이전 도형 의류를 다시 넣지 않습니다.
두 서버의 영구 PostgreSQL 스키마와 저장소에 반영했으며 서버 재시작 후에도 유지됩니다.
공개 HTTPS 터널과 GPU 서버를 종료하거나 재시작하지 않았습니다. `.env`도 접근하지 않았습니다.

## 검증

- 실제 PostgreSQL `fitjang.mentor_demo_v1`, `fitjang_test.ui_preview_local`에서 각 9벌, 종류별 3벌 확인.
- 18개 의류의 속성 및 원본 이미지 정상 조회, `analysis_status=done` 확인.
- 기존 의류·이미지 API 404와 실제 저장소 폴더 삭제 확인. 정리 대기 작업 0건.
- 계정·프로필·전신 사진 파일 해시 및 다른 사용자 데이터 불변 확인.
- 두 계정 모두 새 의류 ID만 포함한 추천 코디 3개 생성 확인.
- 공개·로컬 브라우저에서 9벌과 카테고리별 3벌, 실사 이미지 표시 확인.
- 공개 화면: 데님 팬츠 → 네이비 후디 → 인디고 재킷의 GPU 착샷 생성·표시 완료.
- 로컬 화면: 차콜 슬랙스 → 아이보리 니트 → 트렌치코트의 GPU 착샷 생성·표시 완료.
- 두 최종 이미지 모두 576×864 정상 로딩, 브라우저 오류 로그 없음.
- 화면 증거: `.demo/wardrobe-v2/{mentor,local}-wardrobe.jpg`, `{mentor,local}-tryon.jpg`,
  `browser-verification.json`.

착샷 모델은 아우터를 마지막에 합성하면서 안쪽 상의의 형태·디테일을 바꿀 수 있습니다.
이번 결과에서도 안쪽 니트·후디가 정확히 유지되지는 않았습니다. 이미지 입력 교체와
생성·표시 연동은 완료했으며, 여러 겹의 옷을 정확히 보존하는 품질 개선은 별도 과제입니다.
