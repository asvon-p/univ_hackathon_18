# 대학생 공개 시연: 소스 접근 차단과 직접 회원가입

2026-11-11 기준 공개 주소는 `https://sgy-host.taile39b25.ts.net:8443`이다.
참여자는 `/signup`에서 이메일·비밀번호로 직접 가입한다. 초대 코드와 계정 일괄 발급은 필요 없다.
초대 코드 기능은 로컬·공개 화면뿐 아니라 가입 API·설정에서도 제거했다.
이전 클라이언트는 `invite_code` 필드를 보내지 않아야 한다(추가 필드 오류 422).
가입마다 별도 사용자 ID가 생기며 옷장·추천·피드백은 사용자별로 분리된다.
새 계정에는 `session` 사진 정책을 적용한다. 전신 사진과 착샷은 메모리에서만 처리하고,
로그아웃 또는 30분 미사용 시 삭제한다. 자세한 내용은 [사진 보관 정책](PHOTO_RETENTION.md)을 참고한다.

현재 가입은 이메일 형식만 검사하며 이메일 소유권·대학교 재학 여부를 인증하는 기능은 아니다.

## 공개되는 범위

`인터넷 HTTPS:8443 → Tailscale Funnel → 127.0.0.1:3001 프론트`

- 백엔드 8003, GPU 8010, PostgreSQL 5432는 `127.0.0.1`에서만 수신한다.
- 프로젝트 루트를 정적 파일 서버로 마운트하지 않는다. 폴더 목록이나 원본 파일 다운로드 기능도 없다.
- 프론트의 공개 보안 계층은 소스·설정·숨김 폴더 경로를 **파일 접근 전에** 404로 차단한다.
  `.git`, `.demo`, `.env`, `backend`, `frontend`, `scripts`, `storage` 등과 Python·설정·백업·소스맵 파일이 대상이다.
- URL 대소문자, 반복 인코딩, 역슬래시·상위 경로 접근도 검사한다. 차단 판단에 파일 존재 여부를 조회하지 않는다.
- 웹 편집기·터미널·디버거·직접 백엔드 API 주소는 공개하지 않는다. 공개 프론트의 PUT/PATCH/DELETE 등은 405다.
  옷장·사진 수정은 인증된 서비스 전용 폼/API를 거치며 원본 코드 편집 기능은 제공하지 않는다.
- 업로드는 실제 이미지 바이트를 검사·표준화하고 서버가 생성한 UUID 경로에 저장한다.
  업로드 파일명을 `../../frontend/app.py`로 바꿔도 원본 코드 경로로 쓰지 않는다.
- 시연 백엔드는 `/docs`, `/redoc`, `/openapi.json`을 생성하지 않는다. 개발용 로컬 API 문서 설정은 별도다.
- 실행기는 루프백 바인딩과 프록시 신뢰 대상을 명시하며 자동 코드 재로딩·원격 수정 기능을 켜지 않는다.
  기존 비공개 Tailscale Serve 443 및 다른 PC 서비스를 변경하지 않는다.

## 브라우저 보안

- 현재 시연 호스트만 허용하고 HTTPS 폼은 같은 출처의 Origin 또는 Referer를 요구한다.
- 다른 사이트의 제출 요청은 403. 로그인·회원가입 과도한 요청은 429와 `Retry-After: 60`으로 제한한다.
  단일 프론트 프로세스 기준 동일 접속 주소 가입 20회/분·로그인 60회/분,
  전체 가입 100회/분·로그인 300회/분이다. 성공·실패 시도 모두 계산하며 재시작 시 카운터는 초기화된다.
  학교 공용 네트워크는 같은 외부 IP를 공유할 수 있다.
- HTML 응답마다 무작위 nonce를 발급하여 해당 페이지의 스크립트만 실행하도록 CSP를 설정한다.
  인라인 이벤트 속성 대신 등록된 이벤트 리스너를 사용하고, 동적 문자열을 HTML로 삽입하는 부분도 줄였다.
- 프레임 삽입 금지, MIME 추측 금지, HTTPS 보안 쿠키, 응답 캐시 금지 등의 헤더를 적용한다.
- 촬영 업로드·이미지 자르기·날씨 위치 요청은 정상 동작하도록 허용 범위를 구성한다.

공식 동작 설명: [MDN CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP),
[FastAPI 문서 경로 비활성화](https://fastapi.tiangolo.com/tutorial/metadata/).

## 원본 코드와 화면 코드의 차이

Python 원본·설정·DB 파일은 서버 컴퓨터에 남으며 공개 주소로 열람하거나 수정하는 경로를 제공하지 않는다.
이 PC의 편집기로 수정한 뒤 서버를 재시작하여 반영한다. Git 저장소 권한이나 다른 원격관리 도구의
접근 권한은 이번 웹 서버 설정과 별개이며 이번 변경에서 수정하지 않았다.

HTML·CSS·브라우저 JavaScript는 화면을 표시하기 위해 방문자의 기기로 전송된다.
개발자 도구로 이를 보거나 자기 브라우저에서 바꾸는 것은 막을 수 없으며,
그 동작이 서버의 Python 원본이나 다른 이용자의 화면을 수정하는 권한을 주지는 않는다.
이번 변경은 웹 애플리케이션의 접근 경계를 강화한 것으로, 서버 프로세스 자체를 별도 OS 계정이나
읽기 전용 컨테이너로 격리한 것은 아니다. 프로젝트 전체를 `python -m http.server` 등으로 다시 공개하지 않는다.

`.env`는 직접·간접으로 읽거나 수정하지 않는다. 시연 설정은 실행기의 명시적인 환경변수로 구성하고,
테스트·서버의 파일 감사 훅으로 `.env` 열기를 차단한다. 기존 계정과 데이터는 유지한다.

## 검증 기록

- 접근 경계·회원 인증·사진 정책·프론트 E2E 관련 95개 테스트 통과. DB 연동 검사는 실제 PostgreSQL의
  격리 스키마에서 수행했다. 경로 조작 업로드가 원본 파일을 변경하지 않는 해시 검사도 포함했다.
- 외부 공용 DNS의 Funnel 릴레이를 통해 TLS를 검증하고 소스·폴더 등 13개 경로의 404를 확인했다.
  원본 코드 쓰기 요청은 404, 일반 폼의 PUT은 405, 다른 출처·출처 없는 HTTPS 제출은 403이었다.
  `.env`는 실서버에서 요청하지 않았으며, 하위 애플리케이션 호출조차 없는 차단 단위 테스트로 확인했다.
- 초대 코드 없는 실제 공개 가입 → session 정책·빈 개인 옷장 → 로그아웃 JWT 401을 확인했다.
  이 검사에서 생성한 임시 계정만 삭제했다. 기존 사용자·의류·추천·피드백·이미지는 보존했다.
- 실제 브라우저에서 기존 착샷 2장, 전신 사진 화면, 가입 화면과 비밀번호 보기 버튼 동작을 확인했다.
  초대 코드 입력란은 없고 해당 탐색 중 콘솔의 오류·경고도 없었다.
- 비공개 검증 JSON과 화면 캡처는 Git에서 제외한 `.demo/public-security/`에 있다.
