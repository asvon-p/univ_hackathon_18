# 멘토 HTTPS 시연 · 전신 사진과 GPU 착샷

2026-11-08, 기존 공개 주소를 유지한 채 전신 사진 업로드와 RTX 5090 착샷을 연결했습니다.

- 접속: https://compiler-outcome-olympus-putting.trycloudflare.com/login
- 계정: 기존 `mentor-demo@example.com`과 기존 비밀번호를 그대로 사용합니다.
- 비밀번호·JWT 키·가입 코드는 `.demo/mentor-demo/credentials.json`에 보관하며 이 문서에 기록하지 않습니다.
- 기존 시연 계정·프로필·전신 사진과 비밀번호를 유지합니다. 의류는 아래의 실사 스타일 9벌로 교체했습니다.
- 가상 성인 전신 사진 `person-03.png`를 추가했으므로 로그인 후 바로 착샷을 볼 수 있습니다.

## 멘토 화면에서 사용

1. 기존 시연 계정으로 로그인합니다.
2. **프로필 → 전신 사진**에서 사진을 선택하고 자른 뒤 활용 동의에 체크하고 저장합니다.
   현재 저장한 가상 인물 사진을 사용하면 이 단계는 생략할 수 있습니다.
3. **코디 추천**에서 기온·상황을 선택하고 추천받습니다.
4. 원하는 코디의 **착샷 보기**를 누릅니다. 하의 → 상의 → 선택 아우터 순서로 처리합니다.
5. 완료되면 추천 카드와 확대 창에 착샷이 표시됩니다. **사진 저장**으로 PNG를 받을 수 있습니다.

현재 옷장은 실사 상품 사진 스타일로 생성한 상의·하의·아우터 각 3벌입니다.
도형으로 만든 이전 시연 의류는 제거했습니다. 구성과 파일 위치, 교체 검증은
[시연 옷장 교체 기록](DEMO_WARDROBE.md)을 참고하세요.

## 실행과 보존

현재 시연 서버는 실행 중입니다. 아래 상태 조회로 URL과 GPU 연결 여부를 확인할 수 있습니다.

```powershell
conda activate univ18
$env:FITJANG_SKIP_DOTENV = "1"
python -m scripts.mentor_demo --status
```

서버가 종료된 상태에서 다시 시작:

```powershell
python -m scripts.mentor_demo --tryon
```

기본 실행도 착샷을 활성화합니다. 이미 8010번 GPU 서버가 실행 중이면 인증 키를 확인한 뒤 공유하고,
없으면 GPU 서버를 시작합니다. 사진 화면만 사용할 때는 `--no-tryon`을 지정할 수 있습니다.

현재 GPU는 로컬 프리뷰 실행기가 소유한 8010번 서버를 공유합니다(`tryon_managed=false`).
**현재 로컬 프리뷰와 멘토 시연 관리 프로세스를 유지해야 합니다.** 로컬 프리뷰를 종료했다면
`python -m scripts.frontend_preview --tryon`으로 다시 켜면 멘토 서버가 같은 GPU 주소·키로 연결합니다.
멘토 서버가 직접 GPU를 시작한 경우에는 종료 시 자신이 시작한 GPU만 함께 종료합니다.

종료:

```powershell
python -m scripts.mentor_demo --stop
```

종료해도 계정·DB·사진은 유지됩니다. 터널을 종료하면 다음 시작에서 임시 HTTPS 주소가 바뀔 수 있습니다.
착샷 작업과 프론트 결과 캐시는 메모리에 있으므로 프론트 재시작 후에는 다시 생성합니다.
이번 배포에서는 실행 중인 터널을 검증해 `--reuse-tunnel`로 인계했으므로 기존 주소가 유지됐습니다.
이 옵션은 이전 관리자가 종료되고 저장된 터널만 살아 있는 인계 상황에 사용합니다.

## 연결 구조와 접근 제한

- 외부 HTTPS → Cloudflare 터널 → 프론트 `127.0.0.1:3001`.
- 프론트 → JWT 인증 백엔드 `127.0.0.1:8003` 및 API 키 인증 GPU `127.0.0.1:8010`.
- 백엔드·GPU 포트와 API 키를 외부에 공개하지 않습니다.
- HTTPS 로그인 쿠키는 `Secure`, `HttpOnly`, `SameSite=Lax`를 사용합니다.
- 전신 사진·착샷은 본인 로그인 후 조회하며 `private, no-store`로 응답합니다.
- 공개 화면은 다른 출처에서 오는 폼 요청을 거부합니다.
- `.env`는 로딩하지 않습니다. 실행기와 서버의 감사 훅으로 `.env` 열기를 차단합니다.
- 시연 DB: `fitjang.mentor_demo_v1`, migration `0011`.
- 저장소: `.demo/mentor-demo/storage`; GPU 환경은 `.demo/tryon-runtime`.
