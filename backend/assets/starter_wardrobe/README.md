# 가입 시 제공하는 예시 옷

신규 계정에 아우터·상의·하의 각 3벌을 복사하는 앱 기본 자료입니다.
기존 시연용으로 생성한 가상 의류 이미지이며, 사용자 사진이나 타인의 옷장 데이터가 아닙니다.
아우터는 앞이 열린 버전을 사용합니다. 원본 자료를 JPEG로 표준화하고 384px WebP 썸네일을 함께 준비했습니다.

`catalog.json`은 의류 속성과 파일 SHA-256을 기록합니다. 실제 가입 시 모델 호출 없이
검증된 이미지와 속성을 각 사용자의 전용 경로·의류 ID로 복사합니다.
패키지 배포 시 이 디렉터리 전체를 포함해야 합니다. 실제 사용자의 저장 파일은 이곳에 두지 않습니다.
